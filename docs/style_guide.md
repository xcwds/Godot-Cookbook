# Style guide

GDScript follows the official [GDScript style guide](https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_styleguide.html), checked with `gdlint` and `gdformat` (`tools/check.sh lint`).

Files and folders are `snake_case`, including scenes. Recipe structure is described in [recipe_contract.md](recipe_contract.md).
